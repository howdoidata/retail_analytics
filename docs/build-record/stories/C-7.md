## Story spec

**C-7: Build the sign-ups by channel mart (Ch3)** (CAP-5)

> fct_signups_by_channel: sign-ups per channel and quarter with prior-quarter comparison, share, and cost per signup,
> with the contract's tests (CAP-5).

Decisions in the story spec: spend reaches the mart through a new intermediate model at channel
× day (`int_channel_spend_daily`), so the funnel mart can roll the same model up to months; the grid is
every channel in the `channels` seed × every quarter from the first to the last quarter with a sign-up or
spend, and the prior quarter is one `lag` over that grid, never a query per quarter.

## Change

- PR: pending batch PR. C-7 commits: `80decc0` (the models, tests, and AI review fixes) and the commit that
  adds this record.
- Added `int_channel_spend_daily` (`stg_ad_spend` summed over campaigns to one row per channel and day)
  and `fct_signups_by_channel` in `dbt/models/marts/`, which reads only `dim_customers`, the spend model,
  and the `channels` seed: sign-ups, prior quarter and change, share of the quarter's sign-ups, ad spend,

  tests plus singular tests (sign-ups non-negative, shares sum to 1, prior null only in the first quarter,
  grid complete, mart sign-ups and spend equal their inputs, spend total equals `stg_ad_spend`). Fixtures shaped like `dim_customers` and
  `int_channel_spend_daily` with Python tests (`tests/test_signups_mart.py`) for each case in the story's
  input matrix, broken variants, the contract's column order, and seed 42; the spend model is covered on
  staging fixtures in `tests/test_core_layers.py`. On seed 42 every dbt test passes, the mart has 7 × 8 =
  56 rows, and sign-ups sum to the 18,735 customers. Latest quarter (2025 Q4, all simulated): Paid Social
  1,021 sign-ups at $18.01 per signup, Paid Search 660 at $31.44, Email 240 at $3.02, and Organic Search
  450, In-store 300, Direct/Unknown 283, Referral 207 with no spend.

## Review outcome

- **Human decision:** pending; the change has not had human review yet.
- **AI review findings:** three AI review passes (blind, edge cases, verification gaps) before commit; the
  accepted fixes are in `80decc0`.

| Source | Finding | Decision | Reason |
|---|---|---|---|
| AI review | Spend outside the sign-up quarters is never tested, and no dbt test checks that the grid keeps every sign-up and dollar | Accepted | Added a totals test and a fixture with spend after the last sign-up |
| AI review | Shares-sum tolerance would fail on correct data past about 20 channels | Accepted | Tolerance now scales with the number of channels |
| AI review | `ad_spend` doc block carried a mart-only rule | Accepted | Kept the general definition; the 0 rule stays on the mart column |
| AI review | Spend model description wrong for days whose campaigns sum to 0 | Accepted | Reworded to one row per channel and day in `stg_ad_spend` |
| AI review | Mart `ad_spend` documented never null but untested | Accepted | Added not_null |
| AI review | A test name left out that it also checks spend | Accepted | Renamed |
| AI review | Negative spend never tested | Rejected | The generator never produces it; staging is outside this story |
| AI review | Share in a quarter with no sign-ups not checked by dbt | Rejected | Guarded in SQL and pinned by the exact-row test |
| AI review | Decimal overflow above 10^16 dollars | Rejected | Unreachable for simulated spend, and would fail loudly |
| AI review | No range tests on share, cost, and change | Rejected | They hold by construction from non-negative counts and spend |
| AI review | Column types not enforced by a dbt contract | Rejected | Every column is cast in SQL and the built types are tested |
| AI review | Record's seed-42 figures printed, not asserted | Rejected | A reported measurement of a deterministic seed, as in C-6 |
| AI review | Unknown or null channel arriving through spend untested | Rejected | Upstream relationships and not_null tests fail first |
| AI review | Duplicate-spend case repeated in the mart tests | Rejected | It is the story's covering test for that case on the spend fixture |
| AI review | Empty input untested | Rejected | No real path produces empty sources |
| AI review | `channels` seed loaded by hand in the fixture loader | Rejected | Same pattern as C-6; the seed-42 test runs the real seed |
| AI review | Fixture totals hard-coded | Rejected | Fixed fixtures; exact expectations are the point |
